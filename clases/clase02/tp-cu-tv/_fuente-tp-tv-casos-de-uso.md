*(Imagen: fotografía de un televisor de pantalla plana con base, marca LG, mostrando en pantalla una ola oceánica rompiendo. Es ilustrativa del sistema a modelar; no aporta información adicional al enunciado.)*

1. El usuario podrá encender el sistema presionando el botón del televisor o a través de un control remoto.
2. El usuario podrá cambiar de canal presionando un botón del televisor o a través de un control remoto.
3. El usuario podrá seleccionar cualquier canal disponible presionando un botón o a través de un control remoto.
   a. El televisor acepta las siguientes resoluciones de pantalla 4K y 1920 x 1080.
4. El televisor debe poder conectarse a un sistema de sonido Surround.
5. El televisor debe disponer de conectores a antena digital (por ej. TDA), y a access point inalámbrico (WIFI).
6. El televisor debe proveer una salida de audio-video para un sistema de grabación, como por ejemplo un blue.ray de alta definición.
7. El televisor debe superar las 10.000 horas de uso antes de necesitar mantenimiento de un técnico.
8. El televisor debe estar en el mercado para el año 2019 (cuando estén disponibles contenidos en formato "5K")
9. El sistema deberá respetar las disposiciones legales que regulan los Derechos de Propiedad Intelectual de los contenidos a visualizar.
10. El sistema deberá cumplir las normas que regularizan el uso de redes inalámbricas y digitales.
